# Aurict Roadmap

This roadmap is a direction map, not a promise list. Completed work should be verified through the changelog and release artifacts.

## Phase 01: Working core

Status: live / hardening

- Terminal-native Aurict CLI.
- BYOK provider model.
- Firebase-backed web auth.
- Browser-based login for CLI sessions.
- Mobile BYOK chat, research, and PDF generation.
- Privacy, terms, and account deletion surfaces.
- Scoped assistant-answer reporting from mobile.
- GitHub Releases powered automatic changelog.

## Phase 02: Product hardening

Status: active

- Align mobile and web brand language.
- Harden real-device auth and provider key flows.
- Keep normal mobile chat lightweight through deterministic tool routing.
- Maintain objective system prompts and source-backed research behavior.
- Produce Android release artifacts through signed CI workflows.
- Keep backend prototype secrets and service files out of source control.
- Expand docs, roadmap, legal pages, and security posture documentation.

## Phase 03: Ecosystem expansion

Status: planned

- MicroTarget.one dashboard and process management integration.
- AI-assisted optimization and decision support layer.
- Design/interface generation layer.
- Independent platform foundation for the cybersecurity vertical.

## Phase 04: Research track

Status: research

The long-term research track should be funded by practical product usage. It can explore lower-cost inference, context strategies, alternative model approaches, and agent behavior that is more objective and useful than generic chat interfaces.

## Roadmap policy

Do not market research goals as shipped capabilities. Keep the public product grounded in what exists: CLI orchestration, web trust surfaces, mobile BYOK workflows, account control, feedback reporting, and release discipline.
